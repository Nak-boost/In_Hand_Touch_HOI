# 初始抓取：当前实现与论文的区别

核对日期：2026-10-12。仿真稳定抓取缓存与真机从桌面拾取物体是两个不同任务。

## HORA

论文附录 Stable Precision Grasp Generation：从 canonical grasp 出发，关节角加入
U(-0.25,0.25) rad 扰动，推进仿真0.5秒；保留指尖距物体<10 cm、至少两指接触、
物体高于指定阈值的状态；每个离散尺寸生成50,000个抓取。

公开代码 `hora/tasks/allegro_hand_grasp.py`：预设16个角度，随机扰动，读取实际物体—指尖接触对；
成功状态为16维关节角+7维物体位姿。抓取生成使用CPU数据接口；训练从对应尺寸缓存抽样。
论文摘要描述与这版脚本并非所有细节一致：脚本把物体初始四元数置为单位四元数；
`scripts/gen_grasp.sh` 的50控制步、controlFrequencyInv=8和120 Hz仿真约为3.33秒，
不是论文附录写的0.5秒。不要混用二者的具体时长。

来源：https://arxiv.org/abs/2210.04887 ；本仓库保留的HORA源代码。

## AnyRotate

论文抓取生成部分：掌心朝上，物体初始位置在手基座上方13 cm，随机物体朝向；
canonical grasp 的关节角加 U(-0.3,0.3) rad 扰动。
推进120步、6秒，依次改变重力方向为手坐标系的±X/±Y/±Z，测试不同朝向下的稳定性。

保留条件：指尖接触数量>2（至少3个）、非指尖接触为0、指尖到物体的总距离<0.2 m、
物体全程稳定；每物体10,000个抓取。不是所有物体复用一份关节角。

来源：https://arxiv.org/html/2405.07391v2 。这里引用论文描述，不声称逐项运行了其官方实现。

## 当前项目

- canonical_q 是初版适配时自行选择的工程姿态，不是论文标定结果或最优抓取。
- 关节角扰动±0.22 rad并限幅；球心初值[-0.01,-0.01,0.64] m，XY各扰动±4 mm，初始朝向固定。
- 80控制步约4秒，前25步约1.25秒用于稳定，后续每步都必须通过条件。
- 至少2个胶面与物体有真实接触对，且对应胶面净力>0.1 N；物体线速度<0.1 m/s、角速度<1 rad/s，未触发高度/位移失败条件。
- 使用GPU PhysX+CPU接触数据接口筛选，避免手指自接触误算为物体接触。
- 只使用当前向下重力，不测试六向重力，不禁止手掌/指节/外壳参与支撑；因此比AnyRotate的precision grasp条件宽松。
- 每个物体仅64个缓存，是调试规模；缓存中保存q16+物体位姿7。训练重置时随机抽样、清零速度，设置目标关节角为缓存的实际角度。
- 这意味着没有单独保存筛选过程中原目标角度/预紧力；恢复后必须做保持回放验证。
- 当前64次随机抽样零动作保持5秒，63次未触发失败。这不是64个唯一抓取逐一通过，更不是旋转成功率。

后续扩展形状/尺寸时，应为每个对象几何与尺寸组合建立单独缓存，结合手模型和碰撞签名校验。
对细长、扁平、不规则物体增加物体初始朝向和多个canonical手姿态的采样，再按任务需求筛选。
采样失败应调整放置位置/姿态种子或判定该尺寸不可操作，不应关闭碰撞来提升通过率。
真机需要另外的人工放置或抓取模块，以及接触稳定性检测；仿真缓存不实现真实拾取。
