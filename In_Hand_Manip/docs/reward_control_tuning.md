# 奖励尺度与累积目标限位惩罚（2026-10-14）

后续更新：2026-10-15 新默认控制已改为相对实际关节角，并增加指尖距离奖励。见 [最新控制与奖励说明](distance_actual_control.md)。本文保留为 10 月 14 日实验的历史记录，下面的目标累加公式不是新默认值。

本次调整针对提前失败的回报动机、累积关节目标饱和。默认值用于下一轮受控实验，尚未证明旋转策略收敛。实现涉及 `configs/manip.yaml`、`hora/tasks/manipulation_math.py`、`hora/tasks/allegro_digit_two_axis.py` 和 PPO 的诊断日志汇总。

## 参数与含义

| 参数 | 调整前 | 当前默认 | 含义 |
|---|---:|---:|---|
| `off_axis_weight` | 0.15 | 0.15 | 保留零误差附近的原代价尺度 |
| `off_axis_cost_cap` | 无界 | 0.5 | 加权偏轴代价的平滑上限 |
| `overspeed_weight` | 0.1 | 0.1 | 保留零误差附近的原代价尺度 |
| `overspeed_cost_cap` | 无界 | 0.25 | 加权超速代价的平滑上限 |
| `pose_weight` | 0.3 | 0.05 | 实际关节相对初始抓取姿态的平方偏差 |
| `drop_penalty` | 5 | 250 | 触发任务失败时一次扣分；仅超时不扣 |
| `limit_push_weight` | 0 | 0.25 | 被硬限位裁掉的目标增量代价 |

偏轴/超速原加权代价记为 `x = weight * squared_error`，现在为 `cap*x/(cap+x)`。它在零附近保留一阶尺度，随误差单调增加并渐近于 cap。`cap=0` 恢复原二次形式。桌面配置明确设置的两个 weight=0 继续有效。

姿态项仍为 `-pose_weight*sum((q-initial_q)^2)`，仅降低系数。未增加存活奖励。较大的失败代价也可能使策略更保守，仍须监控旋转量，不能只看存活时间。

## 限位惩罚

保持原来的动作平滑、增量 PD 目标更新和硬限位：

```
requested = action_scale * smoothed_action
target_new = clamp(target_old + requested, lower, upper)
applied = target_new - target_old
blocked = mean(clamp(abs(requested - applied) - 1e-7, min=0)) / action_scale
reward_limit = -0.25 * blocked
```

这里的限位指 **累积目标** 的关节角上下界。它不会惩罚有效的大动作，也不会在合法回撤时罚分；不惩罚“接近限位”本身。动作反向后，平滑器可能暂时仍输出向外增量，此时仍按实际向外被裁掉的增量计费。

归一化用 `action_scale=0.026 rad`，对 16 关节取平均，不采用“损失增量/请求增量”比例。因而一个关节全幅向外推的最大单步代价约 0.015625；16 个关节全部全幅被挡约 0.25；很小的无效指令代价也小。正常策略动作经裁剪和平滑后在 [-1,1] 内。

PPO 的 `bounds_loss_soft_bound=1.1` 约束动作分布均值，继续保留，与此环境奖励是不同层面的约束。此次未改变 PD 控制器、动作尺度、关节限位、碰撞几何或过滤，也未加入目标超前量限制。

## 尺度依据与限制

详见 `../../research/reward_control_tuning_20261014/report.md` 与原始 NPZ/JSON。

第一轮在固定动作轨迹上比较姿态系数 0.3/0.1/0.05/0.03、超速上限 0/0.25；包括零动作、小噪声、持续正向全幅、每 100 步交替方向。每种协议 32 环境×600 控制步。脚本动作不是训练后的策略，改变奖励不会改善这些固定动作的物理表现。

失败代价用 gamma=0.99 的折扣回报估算，而不是直接比较单步成本。对长度 L 的已观测失败回合，去掉终止罚分的折扣回报为 G，则与假想立即扣 D 终止相比，所需 `D >= -G/(1-gamma**(L-1))`（L>1）。这是有限轨迹下的尺度诊断，不是全状态的安全或最优性证明；立即失败基准还省略了动作相关的同一步奖励。

初始两场景给出 D=200 的候选值；原 85 体短探测发现完整回合所需 D 最大约 214.61，加上候选模型较长后缀所需约 227.90，最终选择 D=250 留出余量。临近失败的部分短后缀仍可能偏好更早结束；单纯无限增大 D 会增加价值估计方差和保守程度。PPO 会把全部原始奖励乘 0.01，因此单次失败项进入回报缓冲区约 -2.5。这个缩放不改变相对回报排序。正式训练应同时检查失败率、持续正向转角、偏轴运动及 `control/blocked_target_command`。
