## 新桌面扫描入口

`run_tabletop_scan.sh` 使用独立的 `AllegroDigitScan` 和状态机控制器，不经过 PPO，不更改原训练入口的任务选择、损失或优化器。SciPy 运动学依赖仅由扫描入口导入。扫描场景启用胶面—桌面和胶面间碰撞的覆盖也仅限此子类。

共享环境增加了 cylinder 资产分支；原 sphere、box、capsule 创建分支保持不变。扫描任务不加载抓取缓存或旧权重。正常 RL 训练仍使用 `scripts/run_manip.sh`。

## 此前已经存在、此次一并提交的训练差异

相对原 HEAD `4fba570`：

- `manip_hora16384_sphere55` 及其派生悬空配置的策略网络从 512/256/128 改为 256/256/128，特权编码器从 256/128/8 改为 128/64/8。这是 10 月已有工作区状态，不是本次状态机需要的改动，也不是性能提升结论。旧大网络 checkpoint 不能直接用于小网络恢复；旧实验应按保存配置回放。
- 当前相关配置改用 `*_robust_20261018.pt` 抓取缓存。新增加载时控制/随机化契约检查：缓存包含契约且不匹配时拒绝加载；没有此字段的历史缓存仍受原有资产、物体与碰撞检查约束。
- 桌面任务默认 `terminate_on_contact_loss: false`，允许释放后重新接近；失触仍记录为统计，超出工作区仍失败。需要历史失触终止语义时必须显式设为 true，包括使用缺少此键的旧保存配置时。
- 桌面配置启用 `rotation_contact_multipliers: [0.1, 0.5, 1.0]`，改变连续旋转奖励的接触门控；30° 离散进度奖励沿用原逻辑。
- 增加抓取复验工具、按实际控制周期换算的测试时长，以及独立的拇指显示修正资产。原训练资产没有被该显示资产覆盖。

因此，新扫描功能与 RL 入口独立，但从旧 Git 版本更新后直接使用当前默认配置启动训练，不等价于重跑旧配置。缓存/权重/原始轨迹不上传 Git，另一台机器训练前需要按配置生成或单独同步缓存。
