# 操作模块接口 v1

## 坐标、单位和时间

- SI 单位：米、秒、弧度、牛顿；四元数 `xyzw`。
- 手腕固定在仿真 `(0,0,0.5)`，沿用 HORA 的掌心朝上旋转。
- 控制命令使用**掌心朝上的任务坐标系**：与当前仿真环境世界方向对齐，`+Z` 向上，`+X` 水平。
  它不是 Allegro URDF 的 `base_link` 坐标轴。以后移动手腕时，必须显式转换，不能直接复用当前轴。
- 每条控制命令持续 0.05 s，物理步长 1/120 s。
- 几何与物体位姿真值只供教师、奖励、初始状态和评估；后续纯触觉重建不得将其作为输入。

## 学生每帧 71 维

| 范围 | 含义 |
|---|---|
| 0:16 | 关节位置，按上下限缩放至约 [-1,1] |
| 16:32 | 关节速度 / 5，截断 [-3,3] |
| 32:48 | 当前 PD 目标位置，按关节上下限缩放 |
| 48:64 | 上一个已平滑动作，[-1,1] |
| 64:68 | index/middle/ring/thumb 的胶面二值接触 |
| 68:71 | 单位旋转轴 |

`obs` 是最新一帧，`proprio_hist` 是含最新帧的 30 帧序列。
重置后用第一帧填充历史；换轴时保留历史，只改变轴命令。
历史与当前帧采用教师同一组冻结的观测归一化统计。

教师另外使用 `priv_info[23]`：相对初始位置 3、物体四元数 4、线速度 3、角速度 3、
形状尺寸 3、质量 1、摩擦 1、重心 3、当前段累计旋转量 1、下一增量目标 1。
学生网络即使收到 `priv_info` 键也会主动丢弃；单元测试对此做了检查。

## 动作与关节顺序

策略输出 `a[16]`，先截断，再指数平滑，然后累加到关节目标，增量尺度默认 0.026 rad。
关节目标按关节上下限限制；PD 力矩按 URDF effort 与 0.5 Nm 中的较小值限制。
Isaac Gym 的实际 DOF 顺序是树遍历顺序，可能为 0..3,12..15,4..7,8..11。
不要假设是数字顺序，使用检查点和 `asset_metadata.json` 的 `joint_names`。
`canonical_q` 配置按编号 0..15 写，环境加载时自动映射。

## 缓存与评估

抓取缓存包含手 URDF 的 SHA256、碰撞规则签名、物体清单、实际关节名称及每物体的 `[q16, position3, xyzw4]`。
筛选过程固定关节目标，通过物体重力、PD 和接触稳定性筛选；没有焊接或固定物体。
抓取生成采用 GPU PhysX + CPU 数据接口，检查实际物体—胶面接触对，排除手指自接触造成的假阳性。
教师/学生 checkpoint 同样记录碰撞签名；旧的无自碰撞缓存或权重不能静默续接。
没有足够有效抓取会报错，不回退到普通 Allegro 缓存，也不假造稳定初始状态。

评估记录每个结束 episode 的物体、失败标志、时长、各轴累计有符号角度。
`commanded_axes` 记录当前指令轴，`all_axes_one_turn_rate` 指完整 episode 未掉落且每条指令轴累计投影角至少 2π；
仅两轴任务额外输出兼容字段 `both_axes_one_turn_rate`，单轴任务不再输出该名称。
它不代表物体准确沿轴转完一圈停下，也不保证触觉覆盖完整表面。
仿真真值用于该指标；学生推理输入不含真值。

## 与未来重建模块的边界

由外层记录带时间戳的原始 DIGIT 帧、本体状态、执行动作和传感器外参。
接触点从传感器坐标变换到物体坐标需要物体位姿估计，这不属于本控制模块。
可先由系统层定时切轴，再改为由重建模块的覆盖/不确定性决定轴。
