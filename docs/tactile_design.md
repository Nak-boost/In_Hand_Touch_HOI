# 当前触觉设计与论文的区别

核对日期：2026-10-12。当前实现是 HORA 基础设施上的 AnyRotate-inspired 简化基线，
不是 AnyRotate 完整复现。使用 binary contact 是本项目初版实现的范围选择，
不是 DIGIT 的能力限制，也不是 AnyRotate 的完整触觉表示。

## 当前代码

学生每帧 71 维：16 关节位置、16 关节速度、16 目标关节位置、16 上一步动作、
4 个 binary gel-contact、3 维目标旋转轴；再使用 30 帧历史。
教师另有 23 维物体/物理特权信息，学生部署不读取这些真值。
仿真二值触觉来自独立胶面刚体的净接触力阈值（0.1 N），有一帧延迟及 2% 漏检。
启用自碰撞后，其他手指碰到胶面也会产生这个信号；它不是带物体身份的接触标签。
抓取缓存额外用物体—胶面接触对筛选，学生观测仍保持净触觉语义。
这还不是从真实 DIGIT 图像提取的信号，真实检测器需要实现与标定。

TACTO 未接入训练入口。只使用接触标志时，Isaac Gym 可以直接产生该信号；
为每个并行环境渲染四张触觉图像再压成四个 bit，会增加渲染与数据交换开销。
未进行本项目上的渲染性能基准测试，不声明具体加速倍数。
二值触觉适合作为操作基线，但不提供局部形状、接触位置和滑移信息，
不能替代最终重建模块需要的高分辨率触觉。

## NeuralFeels

论文 Section 4.2 使用 Isaac Gym 物理仿真 + TACTO 触觉渲染。
Section 4.6.2 使用 TACTO 生成配对触觉 RGB/深度，训练 tactile transformer；
由图像估计接触深度，再用于物体形状与位姿估计。
补充材料 S4 描述操作策略：PPO 特权教师，部署时用本体历史估计物理潜变量。
S4 没有把触觉 RGB 或 binary contact 列为旋转策略输入；DIGIT 形态及保持胶面接触
影响策略训练，但“系统使用触觉重建”不等于“旋转控制直接使用触觉图像”。

- 论文：<https://arxiv.org/abs/2312.13469>（4.2、4.6.2、S4）
- 官方代码：<https://github.com/facebookresearch/neuralfeels>

## AnyRotate

Section 3.2、3.4、4.1 及 Appendix F/H/I/J 描述：

- RL 在 Isaac Gym 内训练；刚体碰撞信息转换为触觉特征，不要求 TACTO 图像渲染。
- 每指完整触觉包含 binary contact、接触球面坐标两角 Rx/Ry、三维接触合力的模长。
  四指共 16 维触觉；其完整总观测 95 维，binary 对照 83 维，本体对照 79 维。
- 在真实传感器上采集带位姿/力标签的数据，训练图像到接触特征的观察模型；
  binary 检测基于当前图像与参考图像的 SSIM。
- 实际触觉硬件是定制 DigiTac/TacTip 系列曲面指尖，不是现成平面 DIGIT。
  其曲面接触坐标、力预测模型、阈值不能直接搬到我们的硬件。
- 消融实验中，完整触觉优于 binary/本体版本。只加入二值触觉不等于复现其主要触觉贡献。

论文：<https://arxiv.org/html/2405.07391v2>

## 本项目后续建议（尚未实现）

保留 binary 版本作为基线，长期操作策略增加真实 DIGIT 可可靠提取的接触几何：
接触 mask、传感器坐标下的接触中心、接触面积、压入深度/局部法向及时间变化。
每个特征需要配套仿真提取、真实观测器、噪声/延迟模型和消融评估。
若引入力大小，必须用真实力标签或经过验证的力学模型标定；TACTO 的渲染深度
并不自动给出准确的真实力，刚体仿真合力也不能直接当作部署可观测量。

TACTO 更适合先用于离线触觉观察器训练、少量环境的同步触觉序列和重建模块开发；
大规模操作 RL 可以继续消费与真实观察器对齐的特征。未来若采用图像端到端策略，
再评估训练时触觉渲染及 sim-to-real 的成本。
