# 默认启用胶面—物体接触筛选

2026-10-16。按用户要求启用已有碰撞对筛选，并明确不新增悬空手内任务的失触失败条件。

## 改动

- `configs/manip.yaml` 默认 `object_contact_filter=true`、`pipeline=cpu`；派生手内与桌面配置继承。
- 复用已有 `GelObjectContactReader`：只累加目标物体与各胶面接触点的正法向载荷，超过 0.10 N 才计有效接触。至少两个有效胶面获得接触奖励。
- 桌面任务原有连续 2 秒失触失败使用同一筛选结果。悬空任务仍使用原有高度、位移和非有限状态判定，不增加失触规则。
- 观测仍使用胶面原始净力阈值与原延迟/漏检；物理自碰撞和其他奖励项未改动。外壳惩罚也未改成 object-only。
- CPU 数据管线是 Isaac Gym Preview 4 接触对 API 的要求；PhysX 和 PPO 仍使用 CUDA。显式指定 GPU 数据管线但不关闭筛选会立即报错。
- 历史保存的配置/源代码、训练权重、缓存均未改写。缺少开关的历史解析配置仍保持关闭的兼容行为。
- 更新 README、使用文档及 8 种训练配置的默认启用/管线一致性测试。

## 验证

`scripts/python_manip.sh -m pytest -q tests/test_object_contacts.py tests/test_tabletop.py tests/test_reward_control.py`：26 项通过。覆盖自接触、桌面、地面、外壳排除，接触双方顺序、多点载荷汇总、弱物体接触不被强自接触抬高、失触计时和默认配置。

GPU 3、256 环境、500 个控制步的固定动作桌面回放，共 128,000 个环境步。`verify.py` 对保存的接触载荷逐帧验证：

- 任务接触掩码、接触奖励、失触计时、失败与失败代价全部匹配筛选结果。
- 同状态原始信号的反事实判断中，6,294 个环境步本会获得接触奖励，筛选后不再获得。
- 43,392 个环境步中，原始触觉本会阻止失触失败，筛选后的规则判为失败。
- 这些是禁用自动重置的诊断帧计数，不是独立失败回合或成功率。

原始输出：`tabletop_replay.json`、`tabletop_replay.npz`；逐帧核对：`verification.json`。诊断脚本沿用已有在结果写完后退出进程的做法，未测 destroy_sim 清理时间。
