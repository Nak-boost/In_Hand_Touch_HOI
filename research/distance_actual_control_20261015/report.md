# 距离奖励与实际关节角控制：修改及验证

日期：2026-10-15。说明与参数见 [项目文档](../../In_Hand_Manip/docs/distance_actual_control.md)。仅进行了功能验证，未启动正式训练，也不能由下述短程结果判断旋转性能。

## 修改

- 保留初始姿态惩罚系数 0.05 和至少两路胶面信号时 +0.05 的奖励。
- 新增四个胶面顶点到物体中心的距离奖励，采用 Rotating without Seeing 的有界反距离平均公式，权重 0.1；未新增策略观测。
- 新默认动作目标为 `clamp(q_actual + 0.026 * smoothed_action)`，平滑系数仍为 0.5。限位损失诊断使用相同基准。
- 教师、学生检查点记录控制模式；恢复、蒸馏、评估、回放核对模式；实机适配器采用相同计算。
- 旧配置缺少字段时保留上一目标累加与零距离奖励，以支持历史结果回放。旧控制权重不能直接用于新控制续训。
- 回放入口根据保存的任务名称选择桌面环境，修复原先一律创建无桌面任务的问题。

## 已通过验证

- 定向测试：27 passed（奖励、控制、运行时一致性、接触失败、PPO 边界及回放文件）。
- GPU 0 / PhysX：16 环境 × 100 控制步；100 次目标公式核对通过，32 次回合重置；奖励和观测有限。
- 距离奖励均值约 0.04735，胶面到物体中心距离均值约 0.05326 m；这是脚本动作尺度检查。
- 教师 PPO：512 环境步，2 次更新；学生蒸馏：4 次更新；检查点权重均有限，控制模式均为 actual_position。
- 学生评估：40 控制步、16 个完整短回合；只用于验证接口与重置。
- 学生回放：单环境 2 步，无需放宽源码匹配检查即可通过；不是完整回合性能测试。
- git diff --check 通过。
