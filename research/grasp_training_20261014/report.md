# ed93077 新装配：抓取复查与多物体训练

## 改动范围

基于 `ed930779cc07ab2688301db1805d2a6737428abf` 的官方网格 DIGIT 装配。
在 `In_Hand_Manip/configs/manip.yaml` 增加 `pose_weight: 0.3`，每个控制步奖励新增
`-0.3 * sum((q - q_initial)**2)`。每个环境重置时独立记录实际初始关节角；
后续物体旋转、目标更新不改变该参考姿态。对应原 HORA 的 `poseDiffPenaltyScale: -0.3`。
这项约束实际手部姿态，不直接惩罚物体旋转，也不等价于 PPO 动作边界正则。
已修正的对称动作均值边界正则仍保留：软边界1.1、系数1e-4；没有删除动作变化惩罚。

为适配新的安装几何，重新提议初始手姿和物体中心，并经 PhysX 接触验证。
新增缓存逐行配对的 `targets`，恢复实际关节状态的同时恢复当时PD目标，保留夹持预紧。
历史缓存没有 targets 时仍采用原来的 q 作为目标。姿态正则始终参照实际初始q。
预紧只改变缓存目标，仍使用原PD增益/限力矩，未改变物理参数。
没有修改手部自碰撞、重力、摩擦、力矩限值、物体失败阈值和其他奖励系数。

## 检查方法与含义

每个候选只回放一次，使用独立随机种子20261014分配原有范围内的物理参数。
检查30秒零动作保持（600个控制步），筛选条件是：

- 不触发原掉落/位移/非有限值失败条件；
- 至少两处真实物体—胶面接触的帧占比≥90%；
- 物体接触非胶面部件的帧占比≤10%；
- 初始实际关节角距离限位不足0.03 rad的关节不超过2个。

分别对四个手指的近端屈伸关节做0.08 rad回撤后恢复；要求该指原本接触物体、
实际回撤≥0.02 rad、不掉落并恢复至少两处胶面接触。
“回撤通过”表示合格抓取中至少一个手指满足该诊断，不表示四个手指均通过。
回撤是诊断项，不是硬筛选：真正换指可能需要先建立其他接触。
非胶面接触阈值允许少量瞬时接触，因此“合格”不表示完全没有外壳/指节接触。

缓存数量按实际合格且不重复的状态计，不复制样本凑64个。
单次保持与回撤检查不能证明持续旋转能力，也不能证明所有摩擦/质量条件下都稳定。
胶囊体首轮缓存不足，进行了局部补充搜索；保留首轮和补充搜索的候选、报告与日志。
异常退出情况见 [validation_notes.md](validation_notes.md)，不把写出文件等同于进程正常退出。

23项单元测试通过。CPU PhysX行为检查验证了配对目标恢复、参考姿态保持、局部重置隔离、
历史缓存兼容，以及奖励与公式一致，见 [reset_pose_validation.json](reset_pose_validation.json)。

新增TensorBoard项：`reward/pose_penalty`、`control/target_increment_lost`、
`control/target_at_limit`、`control/torque_at_limit`。
目标增量损失按每环境L1比例取均值，与此前全体增量L1加权比例不能直接等同比较；
力矩饱和取控制步最后物理子步。有效胶面接触筛选使用真实接触对，不是净力二值观测的替代证明。

horizon16、minibatch4096。没有自动启动学生蒸馏，没有混合多物体训练。

为了让最后接触检查优先完成，曾短暂挂起两组训练，恢复时继续原进程和优化器状态。

计划：[experiment_plan.json](experiment_plan.json)。实时状态：[queue_status.json](queue_status.json)。
各组权重、TensorBoard、完整配置、资产与源码快照位于 `../../runs/manip/teacher_<object>_z_official_pose03_20261014_v2_env256/`。

## 显存失败及训练重新安排

最初每组512环境的v1中，sphere65在训练期间发生PhysX显存分配失败：
`PxgCudaDeviceMemoryAllocator fail to allocate memory 2181038080 bytes!! Result = 2`，
随后报CUDA非法内存访问。不能把这次退出算作训练完成，也没有证据说明它由姿态惩罚公式导致。
当时GPU1还承载末轮接触复查，两组训练的内存也高于初始化占用；最初的并行调度没有留够余量。

所有v1日志和权重保留，旧状态在 [queue_status_v1.json](queue_status_v1.json)，
旧计划在 [experiment_plan_v1.json](experiment_plan_v1.json)。停止了仍运行的v1，
统一以v2_env256新目录从头训练六组，不用失败实验权重继续，以保证当前批次配置一致。
