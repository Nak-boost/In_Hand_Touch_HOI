# 桌面旋转任务实现与验证（2026-10-14）

已实现独立的 `AllegroDigitTabletop`，配置为 `In_Hand_Manip/configs/manip_tabletop_box45.yaml`。
初始物体为 45 mm 立方体，掌心朝下，固定手腕，目标沿世界 +Z 转动。
本次完成场景、初始化、碰撞过滤和训练流水线验证，未训练出收敛策略，未启动长期训练。

## 用户要求的对应实现

| 要求 | 实现 |
|---|---|
| 较小桌面摩擦 | 桌面和物体的摩擦属性各 0.1；胶面 1.0、其余手部 0.6 |
| 四个胶面和桌面共用屏蔽位 | 共用 `1<<28`；关闭胶面–桌面、胶面–胶面物理碰撞 |
| 轻接触包围 | 缓慢闭合并筛选 16 个起点，物体由桌面支撑，至少两个有效胶面接触 |
| 触觉丢失/出界失败 | 四路原始触觉全无持续 2 秒，或中心 XY 距操作区中心超过 10 cm |
| 不惩罚翻倒和角度变化 | 无物体姿态角失败/代价，离轴和超速代价为 0 |

每回合 30 秒为时间截断，不算失败；非有限数值直接报错。
其他原有奖励项保留，包含手指关节姿态正则（与物体姿态不同）、位置、线速度、接触及外壳项。
碰撞资产采用已有的 27 形状简化手部，再增加 1 个桌面形状，未继续增加手部凸分解。

## 验证

1. `tests/test_tabletop.py` 与 `tests/test_manipulation.py`：合计 9 项通过。
   验证共用 bit 仅增加授权的胶面过滤、不改变其他手部过滤；桌面仍与其他手部/物体碰撞；
   连续无触觉计时、任一触觉恢复计时清零、并行环境独立和 XY 出界规则。
2. 初版筛选阈值与触觉检测同为 0.1 N，回放发现 2/16 状态在重新随机化后不足两个有效胶面，
   虽无掉落/失触失败仍不满足初始化质量要求。记录保留在 `replay.json`，不作为通过证据。
3. 增加初始化筛选余量到 0.15 N，策略检测仍为 0.10 N。3 批 × 64 候选共获得 23 个合格状态，
   保存其中 16 个到 `cache/digit_tabletop_box45_light_v2.pt`，配套保存 PD 目标。
4. 最终逐个回放全部 16 个状态，各 600 控制步 / 30 秒，seed=214，重新随机化质量、重心和 PD 增益：
   - 16/16 无任务失败；每个采样帧有桌面支撑和至少两个有效物体–胶面接触。
   - 非胶面手部–物体接触为零；观测到的胶面–桌面/胶面–胶面正冲量接触为零。
   - 最大单胶面合力 0.5108 N，最大水平漂移 0.2324 mm。
   - 详细原始结果及物理参数：`replay_v2.json`。
5. 最终配置在 GPU 2 上以 32 个环境完成 4096 agent steps 的教师 PPO 流水线检查，8 个更新周期。
   路径：`runs/manip/tabletop_final_pipeline_check`；参数及日志有限性检查见 `ppo_check.json`。
   这是约每环境 6.4 秒的流程检查，不支持收敛性、完整回合成功率或旋转效果结论。

## 限制与后续使用

共享屏蔽位取消的是物理接触，不是仅抹掉触觉观测，胶面可能穿桌面或其他胶面。
实际 DIGIT 接触桌面仍会有信号，后续实物迁移需重新处理这一差异。
胶面–其他手指/外壳的力仍可能被二值触觉检测到，当前策略不辨认接触物体身份。
30 秒静态回放与短 PPO 检查不代表所有随机化/大动作条件下稳定，也不保证不会通过翻倒获取沿轴角度奖励。
未运行新的学生蒸馏和真实硬件验证；原有 85 形状训练队列保持停止。

实现及运行命令见 `In_Hand_Manip/docs/tabletop_experiment.md`。
通用控制器、观测、PPO 和学生网络复用；场景与失败逻辑在子类中，原掌心朝上任务保留。
