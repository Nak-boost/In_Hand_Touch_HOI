# 纯触觉手内重建：后续文献与选题判断

核查日期：2026-10-12。面向 Allegro＋DIGIT、触觉与本体感知、未知刚体物体的项目。文献事实见 refs/evidence-map.md 和 refs/sources.json；原始全文保存在 sources/。以下创新性判断是基于所核查公开资料的分析，不是查新证明，也不保证检索穷尽。

## 主要判断

NeuralFeels 之后没有相关研究的印象需要纠正。它于 2023-12-20 发布预印本，正式发表于 2024-11-13 的 Science Robotics（Crossref DOI 10.1126/scirobotics.adl0628）。之后不仅有相关工作，而且 Michael Kaess 同时是 NeuralFeels、NormalFlow、GelSLAM、TouchAnything 的共同作者。后续没有都沿用 NeuralFeels 名字，研究分别发展为触觉跟踪/SLAM、稀疏触觉生成式重建和触觉操作。

这个课题仍有价值，但“纯触觉重建”“引入形状先验”“用不确定性指导下一次触碰”单独都不能作为新颖性主张。更值得研究的是：在物体真实地在单手内运动、接触间歇且位姿未知的条件下，如何利用形状先验稳定联合估计，再用可执行动作主动减少几何与位姿歧义。

## 先明确任务条件

这里的“纯触觉”指部署时不使用外部RGB/RGB-D观测，但允许关节编码器、正运动学、动作历史和DIGIT内部相机。训练时可以使用仿真真值，评估时也可以使用动捕/外部扫描作为参考；这些真值不能进入部署输入。

还需分开：

- 固定物体、已知接触位姿的形状补全，与运动物体、未知相对位姿的联合估计。
- 人工移动物体/传感器的感知实验，与机器人自主多指操作。
- 重建已触达表面，与推断未触达区域的完整形状。
- 固定旋转动作采集数据，与重建不确定性真正改变下一步动作。
- 不提供外部视觉，与不提供物体类别、CAD、初始位姿或人工初始化。

对于未知物体，第一帧接触可以定义任意对象参考系；不能把坐标系约定与获得真实物体位姿混为一谈。评估也应避免逐帧利用真值对齐来掩盖漂移。

## 核心文献比较

| 工作 | 已经做到什么 | 与当前目标的关键边界 |
|---|---|---|
| [NeuralFeels](https://arxiv.org/abs/2312.13469)，2023预印本/2024正式发表 | Allegro＋DIGIT手内操作，视触觉SDF与位姿联合估计 | 主系统使用外部RGB-D；旋转控制主要由本体驱动，并非重建驱动探索；形状从头学习 |
| [NormalFlow](https://arxiv.org/html/2412.09617v2)，2024预印本/RA-L 2025卷期 | 法向图驱动的纯触觉6DoF跟踪，支持重建 | 手动滚动珠子等感知实验；不是自主多指重建控制系统；快速滑动仍可失跟踪 |
| [GelSLAM](https://arxiv.org/html/2508.15990v2)，2025预印本/2026版本 | 纯触觉跟踪、回环、失接触后重定位、全局表面重建 | 论文问题设置允许手持物体与传感器；部分定量评测固定物体，动捕仅作真值；未实现机器人自主旋转规划 |
| [Touch2Shape](https://arxiv.org/html/2505.13091v1)，2025 | 触觉条件扩散形状模型，并以生成潜变量指导RL触碰选择 | 仿真采样，使用球面上的50个候选动作；不是连续自由运动物体的触觉SLAM |
| [TouchAnything](https://arxiv.org/html/2604.08945v1)，2026 | 使用预训练2D视觉扩散先验，从稀疏触觉重建3D形状 | 明确假设接触位置由运动学提供；额外提供类别级文本；未解决动态手内接触的未知对象坐标配准 |
| [Grasp, Slide, Roll](https://arxiv.org/html/2602.23206v1)，2026 | 多指手、扩散形状补全、信息导向探索，并比较抓取/滑动/滚动 | 实验九个对象固定在机器人基座坐标系；palm-rolling是手掌在固定对象上滚动，不是物体在单手中自由翻转 |
| [Object Pose Estimation through Dexterous Touch](https://arxiv.org/html/2509.13591v1)，2025 | 双手分工，RL触觉探索与位姿估计 | 一手稳定物体另一手探索，主要在SAPIEN仿真验证；方法段使用FoundationPose的model-based refinement，不能仅按摘要解读为完整无模型SLAM |
| [TACTFUL](https://arxiv.org/html/2606.24712)，2026 | 实物、无视觉、主动探索、触觉扩散补全和对象识别 | 局限明确为已知三对象库与静态物体，不是未知动态物体的通用手内重建 |
| [AURORA](https://arxiv.org/html/2609.08493v1)，2026 | 不确定性/新颖性驱动的主动手内重定向与在线重建闭环 | RGB-D重建与BundleTrack跟踪；低层控制有触觉也不等于重建仅凭触觉 |
| [Physically Grounded 3D Generative Reconstruction…](https://arxiv.org/html/2604.09100v2)，2026 | 生成式先验结合手部本体、多接触一致性与非穿透约束 | 输入包含RGB与可见性信息；相机对齐的生成重建，不是连续纯触觉对象SLAM |

更早的 [tSLAM](https://arxiv.org/html/2204.00035)（2022）和 [AcTExplore](https://arxiv.org/html/2310.08745v2)（2023/2024）也意味着“用RL探索未知物体并靠触觉重建”本身不是新的概念。

上述论文的成功率和几何误差受传感器、物体尺度、可见性、运动与初始化协议影响，不能直接拿数值排名。尤其不能用GelSLAM密集手工扫描的最终精度与稀疏接触形状补全直接比较。

## NeuralFeels团队是否停止了相关研究

不是。NormalFlow、GelSLAM和TouchAnything均包含Michael Kaess，形成与NeuralFeels有作者交集的后续工作。其中前两篇强化触觉几何跟踪/SLAM，TouchAnything直接研究生成先验加稀疏触觉重建。

[PTLD](https://arxiv.org/html/2603.04531v3)（2026）还包含Mustafa Mukadam、Michael Kaess、Tingfan Wu和Jitendra Malik等NeuralFeels共同作者，继续推进触觉操作与sim-to-real。不过它的实物特权数据采集假设已知物体形状，不能当作未知形状重建方法。

公开主页显示，部分原作者的主要工作转向人形机器人、通用操作或其他机构：例如[Suresh](https://suddhu.github.io/)目前介绍其Atlas策略工作，[Mukadam](https://www.mustafamukadam.com/)介绍其Amazon dexterity工作及相关论文。这只能说明研究方向和人员分布变化，不能据此推断团队内部为什么没有推出某个“NeuralFeels 2”。

因此，比较准确的说法是：没有看到同名系统的一条简单续作链，但相关技术和部分共同作者一直有后续研究。

## 为什么完整的纯触觉自主手内系统仍然困难

1. **局部观测歧义。** 平面、光滑球面和重复结构可能产生相似接触。真实存在的对称性不能只靠网络消除。系统需要合理保留姿态或形状的多种假设。
2. **位姿与形状互相依赖。** 形状不准会引起跟踪失败，位姿错又会把新接触融合到错误位置。NeuralFeels明确指出初期SDF不完整导致跟踪更容易失败。
3. **稳定操作与有效感知的目标不一致。** 稳定转动可以反复接触同一区域；探索新表面可能需要失去局部接触、滑动或重新抓持，增加掉落与失跟踪风险。AURORA表明主动规划能改善重建，但其视觉跟踪本身仍是限制。
4. **生成先验容易让错误变得可信。** 完整且平滑的生成形状不等于已被触觉证实。若先验过强，可能把错误物体形状与错误位姿锁在一起，必须检验观测一致性及失败恢复。
5. **真实系统成本。** 多指触觉标定、运动学误差、接触滞后、DIGIT有效接触面积、物体掉落和对象真值采集都会影响实验。NeuralFeels原文也记录了仿真到现实性能差距及部分实机人工干预。

这些是技术上的解释，不能据此宣称作者因为这些困难而停止研究。

## 对当前项目创新性的判断

**仅做“HORA/AnyRotate旋转＋TouchFM补全”，并将模块串接起来：工程验证价值明确，方法创新通常不足。** 将相机移除、使用DIGIT、转两条轴、选择SDF或点云，也不宜分别当作主要贡献。

更有潜力的主问题可以表述为：

> 在没有外部视觉和已知对象模型的条件下，机器人如何在多指手内操作过程中，利用触觉、本体信息和生成式形状先验，维护未知物体形状与位姿的不确定性，并主动选择既可执行又能消除歧义的动作？

需要产生可验证的方法贡献，而不是只增加模块数量。例如：

- **面向未知位姿的形状先验融合。** 不假定触觉已经配准到正确对象坐标系；在多形状/位姿假设下融合多指接触、运动学与非穿透约束，验证对初期稀疏接触和漂移的改进。非穿透约束本身已有先例，创新应在联合推断方式与证据上。
- **兼顾跟踪和重建的动作选择。** 选择动作时同时考虑新表面信息、位姿可观测性和失接触/掉落代价；当跟踪不确定时可优先重访已知区域，而不是总追求新覆盖。信息增益、风险规划本身也不是新概念，需要给出适用于动态多指接触的具体模型。
- **把未知区域与已测表面分开评估。** 让生成先验补全未触达区域，实际接触约束决定可被验证的表面；新触觉反驳先验时能够纠错。生成样本方差不自动等于校准后的不确定性，需要实测验证。

在本次核查的文献里，没有发现一篇同时完整验证“Allegro/DIGIT式自主多指操作、无外部视觉、无对象CAD、动态未知位姿、多指间歇接触、生成式补全和感知驱动动作闭环”的工作。这个交叉点值得研究，但不能把该检索结论直接写成“世界首次”。也不能认为条件叠加得更多就自动产生方法贡献。

## 建议的最小研究路线

第一阶段固定低层旋转策略，优先研究动态位姿未知时的触觉重建。它既能减少控制端变量，也能验证TouchFM先验是否真正有用。需要从真实DIGIT图像恢复局部几何；当前四个binary contact仅可支撑控制基线，不能构成高分辨率重建观测。

第二阶段将高层动作限制为小集合，例如绕两条轴正/反转、暂停、重访。让高层依据形状/位姿不确定性选择低层技能，先不同时重做一整套端到端控制器。已有的两轴旋转是实验平台能力，不作为论文主贡献。

第三阶段在匹配输入和交互预算下验证主动闭环是否优于简单串接。合理的基线和诊断包括：

| 对照 | 主要回答的问题 |
|---|---|
| 固定交替两轴旋转＋无生成先验的几何估计 | 原始接触融合能做到什么 |
| 同样轨迹＋TouchFM生成先验 | 收益是否确实来自先验 |
| 同样估计器＋随机/固定/仅覆盖导向的动作选择 | 主动方法是否优于简单规划 |
| 多指适配的NormalFlow/GelSLAM或其他几何跟踪后端 | 是否超过已有纯触觉感知方法；明确适配而非冒称官方原版 |
| 真值物体位姿＋同一重建器（诊断上界） | 误差来自配准还是形状推断 |
| 外部视觉辅助位姿＋同一系统（辅助参考） | 去除视觉的代价；不与纯触觉方法混报 |

指标应同时包含：位姿误差/漂移、失跟踪与重定位成功率、已测表面精度、未测区域补全、覆盖率、触碰/时间预算、掉落率、人工重置次数及在线延迟。对称物体使用合理的对称性处理或任务相关姿态指标。不要只展示最终完整模型或一个全局Chamfer分数。

对象应从可握持、可安全接触的形状开始，但训练与测试要按对象/几何家族分开。球盒胶囊可验证流水线，不能证明广泛泛化。ABC可提供几何多样性，但需要筛选尺寸、薄壁、尖角、质量和可达接触范围；不要把全ABC难度直接当作可执行的机械手任务定义。

## 建议定位

适合将“纯触觉手内未知物体的形状—位姿联合推断”作为主贡献，将“信息驱动的高层操作选择”作为扩展。这个定位能利用TouchFM现有优势，也能与GelSLAM的几何SLAM、TouchAnything的已知接触位置先验重建，以及AURORA的视觉主动手内重建形成清楚、可实验检验的区别。

这里的价值来自证明：在同样时间和接触预算下，机器人能更早形成可信的物体模型、更少失跟踪，并通过实际操作补足最影响判断的触觉证据。纯粹把物体转一圈并输出一个完整模型，还不足以证明这些贡献。
